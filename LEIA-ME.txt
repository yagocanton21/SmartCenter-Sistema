SMARTCENTER 2.0 - GESTÃO PARA ASSISTÊNCIA TÉCNICA

Documentação completa: README.md

WINDOWS
Instale Node.js 24 ou superior e execute iniciar.bat.
Acesso local: http://localhost:3000

PRIMEIRO ACESSO
Instalações novas: o terminal exibe uma senha aleatória para o login admin.
A troca é obrigatória. Não existe mais a senha padrão admin/admin.
Contas antigas podem entrar com a senha atual e devem trocá-la no primeiro acesso.

DADOS
Os dados ficam no servidor SQLite. Não abra index.html diretamente.
Todos os computadores devem acessar o mesmo servidor.
O arquivo .key ao lado do banco protege segredos dos aparelhos e deve ser preservado.

DOCKER
Instalação nova: docker compose up -d --build --wait --wait-timeout 90
Porta pública padrão: http://IP_DO_SERVIDOR:8093
Dados persistentes no volume smartcenter-data, em /app/data.

ATUALIZAÇÃO DE CONTAINER ANTIGO
Use sh scripts/deploy.sh para preservar e transferir o banco antes de substituir
o container antigo. Consulte README.md antes de atualizar uma instalação existente.

BACKUP
Use a tela de backup como administrador ou npm.cmd run backup.
Não copie somente o arquivo principal de um banco ativo em WAL.
Veja no README.md como preservar a chave e recuperar o banco.

TESTES
npm.cmd test
Os testes usam bancos isolados e não alteram o banco da loja.
